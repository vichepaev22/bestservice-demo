Поиск в соцсетях

Найдите кандидатов по городу и нише. Откройте сообщество, подтвердите компанию и добавьте её в свои источники.

Зачем этот раздел

Помогает выбрать, с кем сравнивать коммуникацию. Размер аудитории не доказывает качество сервиса.

Не знаете, кого сравнить?

Найдите активных конкурентов

Ищем публичные соцсети по городу и виду деятельности вашего проекта. Вы сами подтверждаете, что найденная компания действительно конкурент.

Режим: Демонстрация без поиска. Наличие настройки не гарантирует доступность провайдера. Сначала находим ссылки, затем отдельно проверяем активность источников.

Публичная статическая версия не подключена к поиску и API. Без доступного поиска реальные результаты не создаются.

Как подключить поиск на сервере

Установите зависимости проекта. По умолчанию доступен экспериментальный DDGS без ключа. Режим задаётся через COMPETITOR_SEARCH_PROVIDER в окружении сервера.

  • yandex: автопоиск через Алису / Search API. Нужны YANDEX_SEARCH_ENABLED=1, YANDEX_FOLDER_ID и серверный YANDEX_SEARCH_API_KEY. Запросы платные; включение режима согласуйте с администратором. Ключи не вводятся на этой странице.
  • ddgs: поиск без ключа, если библиотека установлена.
  • searxng: собственный SearXNG с включённым JSON и адресом в SEARXNG_URL. Развёртывается отдельно, не через эту форму.
  • BRAVE_SEARCH_API_KEY: ключ Brave Search для поиска публичных ссылок по городу и деятельности.
  • VK_ACCESS_TOKEN: необязательная альтернатива для поиска сообществ VK. Нужен пользовательский токен с доступом к groups.search, не сервисный токен.

Переменная должна быть доступна работающему приложению. Обновление процесса согласуйте отдельно. После подключения отправьте поиск с тестовым городом и деятельностью: только реальный ответ подтвердит работу провайдера, не наличие ключа само по себе.

Если поиск или сбор публикаций не сработал, используйте промпт для Алисы AI, чтобы найти конкурентов во ВКонтакте и добавить ссылки вручную.

Найти 5 конкурентов во ВКонтакте через Алису AI

Готовый промпт для поиска конкурентов

Ниша и город уже подставлены из проекта или последнего поиска. Алиса получит задачу найти пять разных компаний, проверить источники и вернуть список ссылок на их сообщества.

Ссылка может быть правильной, но сервису не удалось получить публикации за последние 60 дней. Это не доказывает, что их нет. Причины проверки показаны отдельно для каждого источника.

  1. Проверьте первые строки промпта: нишу бизнеса и город. Если нужно, отредактируйте их и нажмите «Скопировать промпт».
  2. Откройте Яндекс, вставьте промпт в строку поиска и перейдите к ответу Алисы AI. Если ответ Алисы не появился, используйте чат Алисы AI и вставьте промпт там.
  3. Откройте и проверьте найденные сообщества. Добавьте ссылки в «Мои источники» по одной, через «Добавить ещё ссылку», затем запустите сбор.

Промпт можно изменить прямо здесь. Цель: пять конкурентов, но если источники подтверждают меньше, Алиса должна вернуть меньше, а не придумывать ссылки.

Открыть Яндекс с Алисой

Это ручной помощник, а не автоматическое подключение Алисы. Кнопка открывает страницу Яндекса: промпт нужно вставить самостоятельно. Ответ ИИ и найденные ссылки требуют проверки. Для сбора публикаций VK может потребоваться настройка доступа на сервере; замена ссылки сама по себе эти ограничения не устраняет.

    Как использовать этот срез для решения, а не просто смотреть цифры

    Сначала проверьте источник. Период, неполнота сбора и неизвестные счётчики важнее места в рейтинге. Большая аудитория может дать больше лайков без лучшего контента.

    Откройте публикации. Найдите повторяющиеся темы: цена, объяснение работ, сроки, гарантия. Высокое число комментариев само по себе не доказывает одобрение: без текстов комментариев причина неизвестна.

    Сформулируйте проверку. Радар выше предварительно связывает темы ваших отзывов и публикаций по локальным правилам. Сверьте полный контекст, прежде чем менять процесс. Число совпадений не доказывает причину низкой оценки или преимущество конкурента.

    CSV для любой площадки: до 1 МиБ, 2000 записей и 10 конкурентов. UTF-8, разделитель запятая или точка с запятой; текст до 10000 символов.

    Колонки: competitor, platform, published_at, text, likes, comments, url. Пустой счётчик означает «неизвестно», число 0 означает ноль. Нужны целые неотрицательные числа.
